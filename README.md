# 🗳️ Online Voting System

A secure and user-friendly web-based voting system designed to conduct digital elections efficiently. The system supports separate elections for **President** and **Vice President**, with an administrator responsible for managing the election and viewing results.

## 📌 About the Project

The Online Voting System is a full-stack web application developed to simplify and digitize the voting process.

The system eliminates the need for manual vote counting and provides an organized platform where administrators can manage elections while voters can cast their votes through a simple interface.

The application supports two separate voting categories:

- 🏛️ **President Election**
- 👤 **Vice President Election**

Each category has its own set of candidates and voting process.

The project was designed with simplicity, usability, and reliable vote management in mind.

## ✨ Features

### 🔐 Admin Authentication
- Secure administrator login
- Only authorized administrators can access management features
- Admin dashboard for managing the election

### 🗳️ Voting System
- Separate voting for President and Vice President
- Candidate selection interface
- Prevents duplicate voting according to the application's voting logic
- Simple and intuitive voting interface

### 📊 Election Results
- Vote counts are recorded automatically
- Results can be viewed by the administrator
- Separate results for each election category

### 🎯 Election Management
- Manage candidates
- Manage election status
- Control when results are displayed
- Maintain organized election data

### 🌐 Full-Stack Architecture
- React-based frontend
- Node.js and Express backend
- REST API communication
- Database integration

### ☁️ Cloud Deployment
- Frontend deployed using Vercel
- Backend deployed using Render
- GitHub-based deployment workflow
